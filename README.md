# Rex-Rotary Corrèze

Application PWA de gestion de la carte commerciale Corrèze.

Fonctions principales :
- authentification Supabase ;
- rôles administrateur / vendeur ;
- secteurs commerciaux par codes postaux ;
- communes du secteur 1 verrouillées ;
- consultation des entreprises qualifiées ;
- fonctionnement installable et cache hors ligne après une première synchronisation.

Le site est prévu pour être publié via GitHub Pages.
